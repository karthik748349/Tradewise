# TradeWise

AI-Powered Paper Trading & Financial Learning Platform.

## Phase 1
- React + Vite frontend
- Spring Boot backend
- PostgreSQL
- Redis
- FastAPI AI service
- Docker Compose
- Professional dashboard shell

## Planned phases
1. Foundation
2. Authentication
3. Paper trading engine
4. Markets and portfolio
5. News
6. AI tutor and analysis
7. Learning and quizzes
8. Testing, security, Docker and deployment

## Run
```bash
docker compose up --build
```

Frontend: http://localhost:5173
Backend: http://localhost:8081/api/health
AI service: http://localhost:8000/health
PostgreSQL: localhost:5432
Redis: localhost:6379
